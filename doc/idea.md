# Идея проекта: парсер промокодов (GUI + EXE)

## Цель
Разработать парсер в виде исполняемого `.exe`-приложения с графическим интерфейсом, который собирает промокоды из результатов поисковых систем.

## Основная задача
Формировать список промокодов на основании выдачи поисковых систем по заданным пользователем ключевым фразам.

## Требования к пользовательскому интерфейсу
- Приложение должно иметь графический интерфейс.
- Пользователь должен иметь возможность выбрать используемые поисковые системы.
- Пользователь должен иметь возможность указать ключевые фразы для поиска.
- Пользователь должен иметь возможность задать глубину поиска по выдаче (количество страниц выдачи для просмотра).

## Формат результата
- Результат должен сохраняться в формате `.xlsx`.
- В выходном файле должны быть:
  - найденные промокоды;
  - ссылки на страницы-источники.
- Пользователь должен иметь возможность выбрать путь сохранения выходного файла.

## Ожидаемый сценарий работы
1. Пользователь запускает `.exe`.
2. В GUI выбирает поисковые системы, вводит ключевые фразы и глубину поиска.
3. Запускает процесс парсинга.
4. Получает `.xlsx`-файл с промокодами и ссылками на источники по выбранному пути.
