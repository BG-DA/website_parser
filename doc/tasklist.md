## Итерации

### Итерация 1 — Каркас проекта и запуск GUI
- [ ] Создать структуру каталогов по `doc/vision.md`.
- [ ] Добавить `src/main.py` и простое окно `PySide6`.
- [ ] Добавить кнопки `Старт` и `Стоп` (без логики).

**Тест итерации:** приложение запускается, окно открывается, кнопки видны.

### Итерация 2 — Ввод параметров и валидация
- [ ] Добавить поля: поисковики, ключевые фразы, глубина, путь сохранения.
- [ ] Сделать базовую валидацию ввода (пустые поля, глубина > 0).
- [ ] Показать ошибки в GUI.

**Тест итерации:** пользователь может корректно заполнить форму и пройти валидацию.

### Итерация 3 — Первый рабочий поток (Google)
- [ ] Реализовать `adapters/google.py`.
- [ ] Получать URL из выдачи по 1 ключевой фразе и глубине 1.
- [ ] Интегрировать вызов адаптера из `parser_flow`.

**Тест итерации:** по нажатию `Старт` приложение получает непустой список URL из Google.

### Итерация 4 — Извлечение промокодов
- [ ] Реализовать загрузку страниц по URL.
- [ ] Реализовать `promocode_extractor.py` (базовые regex-правила).
- [ ] Добавить дедупликацию в памяти (`set`).

**Тест итерации:** из тестовых URL извлекаются промокоды без дублей.

### Итерация 5 — Экспорт в XLSX
- [ ] Реализовать `utils/xlsx_export.py`.
- [ ] Формировать листы `Promocodes` и `Summary`.
- [ ] Сохранять файл по выбранному пути.

**Тест итерации:** после запуска создается `.xlsx` с найденными данными и статистикой.

### Итерация 6 — Многопоточность
- [ ] Добавить `ThreadPoolExecutor` для параллельной работы адаптеров.
- [ ] Потоки запускать по количеству выбранных систем (`1..3`).
- [ ] Стабилизировать сбор результатов в общем потоке.

**Тест итерации:** при выборе нескольких систем сбор работает параллельно и не падает.

### Итерация 7 — Yandex и Rambler
- [ ] Реализовать `adapters/yandex.py`.
- [ ] Реализовать `adapters/rambler.py`.
- [ ] Подключить выбор всех 3 адаптеров в GUI.

**Тест итерации:** каждая из 3 систем может быть включена/выключена и участвует в сборе.

### Итерация 8 — Таймер запросов и остановка
- [ ] Реализовать `utils/rate_limiter.py` (delay + jitter + простой backoff).
- [ ] Применить лимитер к запросам поисковиков и страниц.
- [ ] Реализовать мягкую остановку по кнопке `Стоп`.

**Тест итерации:** запросы идут с задержками; `Стоп` корректно завершает текущий запуск.

### Итерация 9 — Конфиг, логирование, минимальные тесты
- [ ] Добавить `config/config.example.yaml` и загрузку `config/config.yaml`.
- [ ] Добавить редактирование базовых параметров конфига в GUI.
- [ ] Добавить логирование в файл с `run_id`.
- [ ] Написать минимальные smoke-тесты (`pytest`) для happy-path.

**Тест итерации:** настройки применяются, лог создается, smoke-тесты проходят.

### Итерация 10 — Сборка EXE и приемка MVP
- [ ] Добавить команду сборки `PyInstaller onefile`.
- [ ] Собрать `dist/promocode_parser.exe`.
- [ ] Провести ручную smoke-проверку полного сценария.
- [ ] Зафиксировать результат проверки в `README.md`.

**Тест итерации:** `.exe` запускается и выполняет полный сценарий до сохранения `.xlsx`.
